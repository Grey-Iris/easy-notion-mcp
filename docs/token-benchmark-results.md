# Token Benchmark: Notion MCP Servers Compared (SUPERSEDED)

**Superseded by [`.meta/research/token-bench-results-2026-06-13.md`](../.meta/research/token-bench-results-2026-06-13.md).** The measured ~6–7× result and full method live there.

This file previously published a ~92% savings figure (a "95.5% page-read savings" headline, dated 2026-03-20, cl100k-only tokenizer, n=3 favorable page shapes). That figure was retired because it blended axes and baselines, used an approximate tokenizer, and rested on a tiny non-adversarial corpus. The replacement benchmark (completeness-stratified, adversarial corpus, Anthropic-primary tokenizer, committed fixtures) measures reading a page's content at about 6–7× fewer response tokens than the official Notion MCP server. See the superseding doc for the result and method.
